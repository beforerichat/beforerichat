## 🤖 AI Agents & Pipelines

### Butler — personal AI assistant `private`
An AI butler with a multi-level cognitive pipeline and a Zero-Leakage privacy
guarantee: a local masking agent replaces sensitive entities with tokens
before any external model call.
**Stack:** TypeScript · Python · Docker
**AI:** LLM agents in a cognitive pipeline; local masking agent;
adapters to external providers (OpenAI-compatible protocol and others).

### Slovo — vocabulary learning `private`
A Flutter mobile app for learning foreign languages: a word → language analysis →
DB lookup → translations and example sentences → a study card; speech is
synthesized lazily on first playback. Go pipeline backend.
**Stack:** Flutter/Dart · Go · MongoDB · Docker
**AI:** LLM agents (analysis, generation, topic suggestions); text-to-speech model.

### Programmer — recursive coding pipeline `private`
A binary pipeline of coding agents: operator task → secretary dialog →
design tree (architect) → coding tree → checks → report. Fully deterministic flow.
**Stack:** Python · Go · Docker
**AI:** LLM coding agents on deterministic pipeline slots; provider adapters.

### Contact — lead processing `private`
Website contact-form pipeline: validation → language → security →
service relevance → company report. JWT-secured webhook.
**Stack:** Go · Python · Shell
**AI:** LLM agents for relevance and reporting; language detection in code (trigrams).

### Orchestrator — agent orchestration `private`
Orchestration of agent trees. Evolution: myfirstorchestrator (first version) → orchester.
**Stack:** TypeScript · Python · Docker · Shell
**AI:** LLM agent orchestration built on my agent/pipeline models.
